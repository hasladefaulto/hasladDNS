# HasladDNS

**Управление DNS в Windows без лишних телодвижений.**

[![Скачать HasladDNS v1.3](https://img.shields.io/badge/Скачать-HasladDNS%20v1.3-blue?style=for-the-badge)](https://github.com/hasladefaulto/hasladDNS/releases)

</div>

HasladDNS — лёгкая утилита для управления DNS-серверами в Windows. Позволяет переключаться между DNS-профилями, отслеживать изменения сетевых настроек и выполнять базовую диагностику.

## Возможности

- **DNS-профили** — встроенные и пользовательские профили с возможностью добавления, редактирования и удаления.
- **Категории AI / No AI** — ручная маркировка профилей и удобное разделение по категориям.
- **Горячая клавиша** — переключение DNS сочетанием `Ctrl + Alt + D`; сочетание можно изменить в настройках.
- **Мониторинг DNS** — просмотр текущих IPv4 DNS-серверов и обнаружение неожиданных изменений.
- **Уведомления** — сообщения о недоступности DNS, неожиданных изменениях настроек и ошибках применения профиля.
- **Диагностика сети** — очистка DNS-кэша Windows и проверка доменов с помощью `nslookup`.
- **Системный трей** — сворачивание приложения и быстрый доступ к основным действиям.
- **История профилей** — список трёх последних использованных DNS-профилей.
- **Резервное копирование** — экспорт и импорт профилей через JSON.
- **Тёмная и светлая темы** — оформление интерфейса на выбор.
- **Только IPv4** — приложение изменяет настройки DNS для IPv4; настройки IPv6 не меняются.

## Установка

1. Откройте [раздел релизов HasladDNS](https://github.com/hasladefaulto/hasladDNS/releases).
2. Скачайте `HasladDNS.exe` из раздела **Assets** последнего релиза.
3. Запустите приложение от имени администратора, чтобы разрешить изменение системных DNS-настроек.
4. Выберите нужный профиль и примените настройки. Для быстрого переключения используйте `Ctrl + Alt + D`.

## Сборка из исходников

1. Скачайте или клонируйте исходный код репозитория.
2. Распакуйте архив в отдельную папку.
3. Запустите `build.bat`.
4. После успешной сборки запустите созданный `HasladDNS.exe`.

Сборка использует компилятор C# из .NET Framework.

## Хранение настроек

Профили и настройки приложения хранятся в каталоге:

```text
%AppData%\HB AI Smart DNS\
```

- `profiles.xml` — сохранённые DNS-профили.
- `theme.txt` — выбранная тема.
- `settings.json` — настройки, горячая клавиша, уведомления и история последних профилей.

Перед обновлением рекомендуется сохранить резервную копию пользовательских профилей.

## Безопасность и ограничения

- Программа изменяет настройки IPv4 DNS; настройки IPv6 остаются без изменений.
- Используйте только DNS-серверы, которым доверяете.
- Успешный ответ `nslookup` не гарантирует доступность самого сайта или сервиса.
