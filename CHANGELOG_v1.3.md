# HasladDNS 1.3

## Что нового

- **Категории AI / No AI:** теперь можно вручную помечать DNS-профили и разделять их по назначению.
- **Компактный интерфейс:** обновлено расположение элементов управления, чтобы основное управление профилями занимало меньше места.
- **Управление профилями:** сохранены встроенные и пользовательские профили, а также возможность добавлять, редактировать и удалять собственные записи.
- **Настройки и горячая клавиша:** настройки открываются отдельной кнопкой-шестерёнкой; глобальная горячая клавиша по умолчанию — `Ctrl + Alt + D`.
- **Диагностика и мониторинг:** текущие IPv4 DNS-серверы, уведомления об ошибках и неожиданных изменениях, очистка DNS-кэша и проверка через `nslookup`.
- **История:** отображаются три последних использованных DNS-профиля.

## Установка

1. Скачайте `HasladDNS.exe` из раздела Assets этого релиза.
2. Запустите приложение от имени администратора, чтобы оно могло менять системные DNS-настройки.
3. Выберите профиль и примените его. Для быстрого переключения используйте `Ctrl + Alt + D`.

## Важно

- HasladDNS изменяет DNS-настройки IPv4. Настройки IPv6 приложение не меняет.
- Используйте только DNS-серверы, которым доверяете.
- Если обновляетесь с предыдущей версии, перед обновлением сохраните резервную копию пользовательских профилей.
